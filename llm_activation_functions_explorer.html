게이팅 메커니즘 (Gated Linear Units)의 2차 상호작용

SwiGLU는 게이트 경로 $a = x W_{gate}$와 정보 통과 경로 $b = x W_{up}$ 두 입력을 받아 $\text{Swish}(a) \times b$ 형태로 곱합니다. 아래 히트맵과 단면도를 통해 게이트 $a$가 $b$의 흐름을 어떻게 동적으로 조절하는지 확인하세요.

🔍 게이팅의 핵심 동작 원리

1. $a \gg 0$ (Gate Open): $\text{Swish}(a) \approx a$가 되어 신호 $b$가 강하게 통과하고 2차 상호작용($a \cdot b$)이 발생합니다.
2. $a \ll 0$ (Gate Closed): $\text{Swish}(a) \approx 0$으로 수렴하여 $b$의 어떤 값이 들어와도 출력을 차단(0)합니다.
3. $a \approx 0$ (Soft Transition): 불연속 없이 부드럽게 필터링 비율을 제어합니다.

Standard FFN

2-Matrix 구조 (GELU / ReLU)

GPT-3, BERT
$$\text{FFN}(x) = \text{GELU}(x W_{up} + b_1) W_{down} + b_2$$
입력 차원 ($d_{model}$) 4,096
↓ $W_{up} : d_{model} \rightarrow 4d_{model}$ (16,384)
Nonlinear: GELU($\cdot$) Point-wise
↓ $W_{down} : 4d_{model} \rightarrow d_{model}$ (4,096)
총 파라미터 계수 $2 \times (d \times 4d) = \mathbf{8d^2}$
Modern Standard (GLU)

3-Matrix 구조 (SwiGLU)

LLaMA 3, Mistral, PaLM
$$\text{SwiGLU}(x) = \left( \text{Swish}(x W_{gate}) \otimes x W_{up} \right) W_{down}$$
입력 차원 ($d_{model}$) 4,096
↓ Split: $W_{gate}$ (Gate) & $W_{up}$ (Up) ($\approx \frac{8}{3}d_{model}$)
Bilinear: $\text{Swish}(a) \otimes b$ Gated Filter
↓ $W_{down} : \frac{8}{3}d_{model} \rightarrow d_{model}$
동일 FLOPs 기준 파라미터 $3 \times (d \times \frac{8}{3}d) = \mathbf{8d^2}$

주요 활성화 함수 수식 및 특성 레퍼런스

함수명 정의 수식 $f(x)$ 도함수 $f'(x)$ 주요 특징 및 LLM 활용
Swish / SiLU $$x \cdot \sigma(\beta x) = \frac{x}{1 + e^{-\beta x}}$$ $$\beta f(x) + \sigma(\beta x)(1 - \beta f(x))$$ 부드러운 비단조성, 음수 영역 미세 통과로 죽은 뉴런 방지 (LLaMA, Mistral)
GELU $$x \cdot \Phi(x) \approx 0.5x(1 + \tanh(\sqrt{2/\pi}(x + 0.044715x^3)))$$ $$\Phi(x) + x \cdot \phi(x)$$ 확률적 정규분포 게이팅 기반의 부드러운 비선형성 (GPT-3, BERT)
ReLU $$\max(0, x)$$ $$1 \text{ if } x > 0 \text{ else } 0$$ 가장 빠른 연산 속도, 0 이하에서 기울기 0으로 Dying ReLU 발생 가능
SwiGLU $$\text{Swish}(x W_{gate}) \otimes (x W_{up})$$ $$\text{Bilinear Gradient}$$ 2차 상호작용 및 문맥 적응형 동적 필터링으로 현대 LLM의 표준
