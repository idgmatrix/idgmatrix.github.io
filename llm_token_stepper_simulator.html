어텐션 행렬 연산 상세 파이프라인 (Step-by-Step Attention Engine)

현재 $Q_t$가 캐시된 $K, V$와 어떻게 행렬 곱셈 $\rightarrow$ 스케일링 $\rightarrow$ 소프트맥스 $\rightarrow$ 가중합($V$)을 수행하는지 추적합니다.

1. 내적 & 스케일링 S = Q_t K^T / √4
2. 소프트맥스 (확률 α) α = Softmax(S)
3. Value 가중합 결과 O_t = Σ (α_i × V_i)
다음 레이어로 전달될 합성 문맥 벡터 (dim=4):
Attention Equation: Context = Softmax( Q1 · [K1]T / 2 ) · [V1]

1. Query (검색어)

새 토큰이 생길 때만 순간적으로 계산되고, 이전 $K$들과 내적 후 다음 토큰을 뽑자마자 폐기됩니다. 영구 보관할 필요가 없습니다.

2. Key (인덱스 카드)

미래의 토큰들이 자신을 찾아올 수 있도록 주소/식별자 역할을 합니다. KV 캐시 테이블에 남아 지속적으로 검색에 응합니다.

3. Value (실제 책 본문)

Key로 선택된 강도($\alpha$)만큼 가중 평균되어 다음 레이어로 넘어갈 순수한 의미 정보입니다. 역시 KV 캐시에 계속 상주합니다.
